# Fotografías de vehículos

Las imágenes actuales del proyecto son recursos de ejemplo.

Para una unidad con varias fotografías, puedes usar por ejemplo:

vehiculos/
  foton-view-c2-alto/
    01-frente.jpg
    02-trasera.jpg
    03-lateral.jpg
    04-interior.jpg
    05-tablero.jpg
    06-motor.jpg

Después, en `data/vehicles.js`, la propiedad `galeria` puede apuntar a esas rutas.
